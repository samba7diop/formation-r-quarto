4  Acquisition et importation des données

4.1 Introduction

Avant d’analyser, il faut obtenir les données et les lire correctement dans R. Ce chapitre couvre les sources courantes (CSV, Excel, texte), l’export, les jeux intégrés, les chemins de fichiers, ainsi que les principes d’accès aux bases et au Web — le tout de façon utilisable hors ligne une fois les fichiers présents dans data/.

4.2 Objectifs pédagogiques

  • Identifier les principales sources de données
  • Importer CSV, Excel et fichiers texte
  • Exporter des résultats
  • Gérer les chemins et le dossier de travail
  • Vérifier la qualité d’un import
  • Comprendre (sans dépendance réseau) bases de données et API

4.3 Prérequis

Chapter 3 (data frames, fonctions). Fichiers disponibles dans data/.

4.4 Comprendre les sources de données

Source Exemple Package / fonction
CSV exports ERP, open data readr::read_csv, read.csv
Excel fichiers métier readxl::read_excel
Texte logs, exports TSV read.table, read_tsv
R intégré mtcars, iris data()
Base SQL PostgreSQL, SQLite DBI, RSQLite
API / Web JSON, HTML httr2, jsonlite
Vocabulaire
  • Encodage : représentation des caractères (UTF-8 recommandé).
  • Séparateur : , ; ou tabulation entre colonnes.
  • En-tête : première ligne = noms de variables.
  • Données brutes : fichier original non modifié.

diagnostiquer <- function(chemin) {
  x <- read_csv(chemin, show_col_types = FALSE)
  tibble(
    fichier = basename(chemin),
    n_lignes = nrow(x),
    n_cols = ncol(x),

    n_doublons = sum(duplicated(x))
  )

# Acquisition et importation des données {#sec-acquisition}

## Introduction

Avant d'analyser, il faut **obtenir** les données et les **lire correctement** dans R. Ce chapitre couvre les sources courantes (CSV, Excel, texte), l'export, les jeux intégrés, les chemins de fichiers, ainsi que les principes d'accès aux bases et au Web — le tout de façon utilisable hors ligne une fois les fichiers présents dans `data/`.

## Objectifs pédagogiques

- Identifier les principales sources de données
- Importer CSV, Excel et fichiers texte
- Exporter des résultats
- Gérer les chemins et le dossier de travail
- Vérifier la qualité d'un import
- Comprendre (sans dépendance réseau) bases de données et API

## Prérequis

@sec-fondements-r (data frames, fonctions). Fichiers disponibles dans `data/`.

## Comprendre les sources de données

| Source | Exemple | Package / fonction |
|--------|---------|-------------------|
| CSV | exports ERP, open data | `readr::read_csv`, `read.csv` |
| Excel | fichiers métier | `readxl::read_excel` |
| Texte | logs, exports TSV | `read.table`, `read_tsv` |
| R intégré | `mtcars`, `iris` | `data()` |
| Base SQL | PostgreSQL, SQLite | `DBI`, `RSQLite` |
| API / Web | JSON, HTML | `httr2`, `jsonlite` |

::: {.callout-note}
## Vocabulaire
- **Encodage** : représentation des caractères (UTF-8 recommandé).
- **Séparateur** : `,` `;` ou tabulation entre colonnes.
- **En-tête** : première ligne = noms de variables.
- **Données brutes** : fichier original non modifié.
:::

    n_cols = ncol(x),
