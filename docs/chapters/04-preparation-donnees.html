5  Nettoyage et préparation des données

5.1 Introduction

Des données mal préparées produisent des analyses trompeuses. Ce chapitre enseigne le nettoyage et la transformation avec dplyr, tidyr, stringr et lubridate : renommer, filtrer, créer des variables, traiter les NA, détecter doublons et aberrants, joindre des tables et pivoter.

5.2 Objectifs pédagogiques

  • Examiner et comprendre la structure d’un jeu de données
  • Chaîner des verbes dplyr (%>% / |>)
  • Traiter NA, doublons et valeurs aberrantes
  • Manipuler textes et dates
  • Agréger, joindre et pivoter
  • Construire un pipeline reproductible

5.3 Prérequis

  1. Packages : tidyverse, janitor (utile), lubridate.
library(tidyverse)
library(lubridate)
if (requireNamespace("janitor", quietly = TRUE)) {
  library(janitor)
} else {
  message("Package janitor non installé : clean_names() sera illustré sans exécution forcée.")
}

5.4 Qualité des données

Une bonne qualité implique : types corrects, noms cohérents, peu de NA injustifiés, pas de doublons involontaires, valeurs dans des plages plausibles, documentation des règles de nettoyage.

Règle d’or

Ne modifiez jamais le fichier brut. Créez une version nettoyée via un script.

5.16 Pipeline de préparation reproductible

preparer_ventes <- function(chemin = "data/ventes.csv") {
  read_csv(chemin, show_col_types = FALSE) |>
    distinct() |>
    mutate(
      date = as.Date(date),
      region = str_trim(region)
    ) |>
    filter(!is.na(region), !is.na(quantite), montant > 0) |>
    mutate(
      mois = floor_date(date, "month"),
      produit = factor(produit),
      region = factor(region)
    )
}

5.18 Erreurs fréquentes

Erreur Cause Solution
filter(region == NA) Mauvaise syntaxe is.na(region) / !is.na
Jointure qui multiplie les lignes Clé non unique Vérifier count(client_id)
summarise sans group_by voulu Oubli Contrôler le nombre de lignes résultat
Dates en character Pas de parsing ymd() / as.Date()

Types de jointures : `left_join`, `inner_join`, `full_join`, `anti_join` (non appariés).

## Pipeline de préparation reproductible

```{r pipeline}
preparer_ventes <- function(chemin = "data/ventes.csv") {
  read_csv(chemin, show_col_types = FALSE) |>
    distinct() |>
    mutate(
      date = as.Date(date),
      region = str_trim(region)
    ) |>
    filter(!is.na(region), !is.na(quantite), montant > 0) |>
    mutate(
      mois = floor_date(date, "month"),
      produit = factor(produit),
      region = factor(region)
    )
}

ventes_clean <- preparer_ventes()
glimpse(ventes_clean)
```

```{r sauver-clean, eval=FALSE}
write_csv(ventes_clean, "data/ventes_clean.csv")
```

## Erreurs fréquentes

| Erreur | Cause | Solution |
|--------|-------|----------|
| `filter(region == NA)` | Mauvaise syntaxe | `is.na(region)` / `!is.na` |
| Jointure qui multiplie les lignes | Clé non unique | Vérifier `count(client_id)` |
| `summarise` sans `group_by` voulu | Oubli | Contrôler le nombre de lignes résultat |
| Dates en character | Pas de parsing | `ymd()` / `as.Date()` |

## Points clés

- Un pipeline clair bat une série de clics manuels.
- Chaque transformation doit être **justifiée** et **vérifiable**.
- Jointures et pivots sont au cœur de la mise en forme analytique.
