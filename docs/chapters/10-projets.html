11.1 Introduction

Les projets suivants consolident l’ensemble du parcours. Chaque projet comporte : énoncé, objectifs, données, étapes, résultats attendus et solution détaillée. Faites l’exercice avant de lire la correction.

11.2 Projet 1 — Analyse des ventes

11.2.1 Énoncé

Vous êtes analyste pour une petite entreprise de papeterie. On vous confie data/ventes.csv.

11.2.2 Objectifs

  • Nettoyer les données (NA, doublons)
  • Calculer le CA par région et par produit
  • Produire 2 graphiques commentés
  • Rédiger 5–10 lignes de conclusions

11.2.3 Étapes recommandées

  1. Import + diagnostic
  2. distinct(), filtre NA
  3. Agrégats dplyr
  4. Barres CA région + boxplot montants produit
  5. Synthèse écrite

11.2.4 Résultats attendus

  • Table CA par région triée
  • Au moins un outlier ou NA documenté
  • Conclusions actionnables (ex. : région / produit à suivre)

11.2.5 Solution

library(tidyverse)

ventes <- read_csv("data/ventes.csv", show_col_types = FALSE)
cat("Doublons :", sum(duplicated(ventes)), "\n")
#> Doublons : 1
cat("NA region :", sum(is.na(ventes$region)), "\n")
#> NA region : 2
ventes_c <- ventes |>
  distinct() |>
  filter(!is.na(region), !is.na(quantite))

ca_region <- ventes_c |>
  group_by(region) |>
  summarise(ca = sum(montant), n = n(), .groups = "drop") |>
  arrange(desc(ca))
ca_region
#> # A tibble: 4 × 3
#>   region    ca     n
#>   <chr>  <dbl> <int>
#> 1 Ouest  7610.    58
#> 2 Est    7141.    50
#> 3 Sud    5995.    42
#> 4 Nord   5096.    47
ggplot(ca_region, aes(reorder(region, ca), ca)) +
  geom_col(fill = "#1a5276") +
  coord_flip() +
  labs(title = "CA par région", x = NULL, y = "CA") +
  theme_minimal()

11.3.1 Énoncé

Explorez data/demographie.csv : structure de la population, revenus, aberrant âge/revenu.

11.3.2 Objectifs

  • Détecter et traiter les valeurs aberrantes
  • Résumer âge et revenu par ville et sexe
  • Tableau croisé sexe × niveau d’études

11.3.3 Solution

demo <- read_csv("data/demographie.csv", show_col_types = FALSE)

# Aberrants évidents
demo |> filter(age > 100 | revenu_mensuel > 20000)
#> # A tibble: 2 × 6
#>      id   age sexe  ville revenu_mensuel niveau_etudes
#>   <dbl> <dbl> <chr> <chr>          <dbl> <chr>

11.4 Projet 3 — Météo

11.4.1 Énoncé

À partir de data/meteo.csv, décrivez la saisonnalité température / précipitations.

11.4.2 Solution

meteo <- read_csv("data/meteo.csv", show_col_types = FALSE) |>
  mutate(date = as.Date(date), mois = floor_date(date, "month"))

mensuel <- meteo |>
  group_by(mois) |>
  summarise(
    temp = mean(temperature_c),
    pluie = sum(precipitations_mm),
    .groups = "drop"
  )

ggplot(mensuel, aes(mois, temp)) +
  geom_line(color = "#148f77", linewidth = 1) +
  labs(title = "Température moyenne mensuelle", x = NULL, y = "°C") +
  theme_minimal()
cor(meteo$temperature_c, meteo$humidite_pct)
#> [1] -0.007141184

11.5 Projet 4 — Régression

11.5.1 Énoncé

Avec data/etudes_notes.csv, modélisez la note selon les heures d’étude et la filière.

11.5.2 Solution

library(broom)
etudes <- read_csv("data/etudes_notes.csv", show_col_types = FALSE)

mod <- lm(note_examen ~ heures_etude + filiere, data = etudes)
tidy(mod)
#> # A tibble: 4 × 5
#>   term            estimate std.error statistic  p.value
#>   <chr>              <dbl>     <dbl>     <dbl>    <dbl>
#> 1 (Intercept)      46.9        1.89    24.8    1.50e-43
#> 2 heures_etude      2.29       0.132   17.3    2.81e-31
#> 3 filiereLettres    0.0554     1.88     0.0294 9.77e- 1
#> 4 filiereSciences  -0.172      1.76    -0.0982 9.22e- 1
glance(mod) |> select(r.squared, adj.r.squared, sigma)
#> # A tibble: 1 × 3
#>   r.squared adj.r.squared sigma
#>       <dbl>         <dbl> <dbl>
#> 1     0.761         0.754  7.45
ggplot(etudes, aes(heures_etude, note_examen, color = filiere)) +
  geom_point(alpha = 0.75) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(title = "Notes vs heures d'étude") +
  theme_minimal()

Rappel : une association positive n’implique pas que « forcer » des heures supplémentaires produira le même effet hors échantillon (causalité, motivation, etc.).
