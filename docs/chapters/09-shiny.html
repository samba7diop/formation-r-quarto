10.1 Introduction

Shiny permet de créer des applications web interactives entièrement en R : l’utilisateur manipule des entrées (listes, curseurs, filtres) et voit statistiques et graphiques se mettre à jour. Ce chapitre couvre la structure UI/serveur, la réactivité, la validation, un mini tableau de bord et l’application fournie dans shiny-app/.

10.2 Objectifs pédagogiques

  • Expliquer l’architecture d’une app Shiny
  • Créer entrées, sorties et réactivité
  • Filtrer des données et afficher graphiques / tables
  • Valider les entrées et organiser le code
  • Lancer l’application locale du projet

10.16 Exemple minimal exécutable (concept)

library(shiny)
library(ggplot2)

ui <- fluidPage(
  titlePanel("Histo mtcars"),
  selectInput("var", "Variable", choices = names(mtcars)),
  plotOutput("hist")
)

server <- function(input, output, session) {
  output$hist <- renderPlot({
    ggplot(mtcars, aes(.data[[input$var]])) +
      geom_histogram(bins = 15, fill = "#1a5276", color = "white") +
      theme_minimal()
  })
}

# shinyApp(ui, server)

# Applications interactives avec Shiny {#sec-shiny}

```{r structure-shiny, eval=FALSE}
ui <- fluidPage(
  titlePanel("Titre"),

server <- function(input, output, session) {
  # logique
}

shinyApp(ui, server)
```

## Interface utilisateur et serveur

- **UI** : ce que l'utilisateur voit et manipule (`inputId`)
- **Serveur** : calcule `output` à partir de `input` via des fonctions `render*`

## Entrées utilisateur

| Fonction | Usage |
|----------|--------|
| `selectInput` | liste déroulante |
| `sliderInput` | curseur numérique |
| `checkboxInput` | case à cocher |
| `dateRangeInput` | période |
| `textInput` | texte libre |

## Sorties

| `render*` | `*Output` |
|-----------|-----------|
| `renderPlot` | `plotOutput` |
| `renderTable` / `renderDataTable` | `tableOutput` / `dataTableOutput` |
| `renderText` / `renderPrint` | `textOutput` / `verbatimTextOutput` |

## Réactivité

```{r reactivite, eval=FALSE}
donnees_filtrees <- reactive({
  req(input$region)
  ventes |> filter(region == input$region)
})

output$resume <- renderPrint({
  summary(donnees_filtrees()$montant)
})
```

- `reactive()` : expression mise en cache, recalculée si dépendances changent
- `req()` : attend qu'une entrée soit disponible
- `observe()` / `observeEvent()` : effets de bord (pas de valeur de retour)

```{r mini-app, eval=FALSE}
library(ggplot2)

ui <- fluidPage(

server <- function(input, output, session) {
```

## Erreurs fréquentes

| Erreur | Cause | Remède |
|--------|-------|--------|
| Sortie vide | Oubli de `output$` / `render*` | Vérifier les IDs identiques UI/serveur |
| Non-réactif | Lecture `input` hors reactive | Envelopper dans `reactive`/`render` |
| Chemin data | Mauvais working directory | Chemins relatifs à `app.R` |
| App qui ne démarre pas | Package manquant | `install.packages("shiny")` |
