2  Introduction à l’analyse de données

2.1 Introduction

L’analyse de données consiste à transformer des informations brutes en connaissances utiles pour décider, comprendre ou communiquer. Que vous étudiiez des ventes, des notes d’examen ou des températures, le raisonnement reste le même : collecter, préparer, explorer, modéliser et présenter.

Ce chapitre pose les bases : à quoi sert l’analyse de données, pourquoi R est un excellent choix, comment installer les outils, puis écrire et organiser votre premier programme.

2.2 Objectifs pédagogiques

À la fin de ce chapitre, vous serez capable de :

  • Définir l’analyse de données et ses étapes principales
  • Expliquer les atouts de R pour la statistique et la science des données
  • Installer et vérifier R, Quarto et RStudio
  • Exécuter un premier script R
  • Organiser un projet d’analyse de façon reproductible

2.3 Prérequis

Aucun prérequis en programmation. Une familiarité basique avec l’ordinateur (fichiers, dossiers, installation de logiciels) suffit.

2.4 Qu’est-ce que l’analyse de données ?

2.4.1 Une démarche en étapes

  1. Question — Que veut-on savoir ? (ex. : « Les ventes ont-elles augmenté au 2ᵉ semestre ? »)
  2. Données — Où sont les informations ? (fichiers, bases, enquêtes…)
  3. Préparation — Nettoyer, filtrer, joindre, corriger
  4. Exploration — Résumer, visualiser, repérer des patterns
  5. Analyse — Tests, modèles, incertitude
  6. Communication — Rapport, tableau de bord, présentation
Vocabulaire essentiel
  • Variable : une caractéristique mesurée (âge, prix, région).
  • Observation : une ligne, un individu, une mesure.
  • Jeu de données (dataset) : tableau structuré de variables et d’observations.
  • Reproductibilité : pouvoir refaire l’analyse et obtenir le même résultat.

2.4.2 Domaines d’application

R est utilisé en biologie, économie, marketing, épidémiologie, sciences sociales, finance, éducation, environnement, etc. Le point commun : des données tabulaires et un besoin de transparence méthodologique.

2.5 Pourquoi apprendre R ?

R est un langage libre, spécialisé dans la statistique et la visualisation. Ses atouts :

Atout Explication
Gratuit et open source Pas de licence payante pour démarrer
Écosystème riche Des milliers de packages (tidyverse, ggplot2, shiny…)
Qualité graphique Graphiques publication-ready
Reproductibilité Scripts + Quarto = analyses documentées
Communauté Forums, livres, formations abondantes
R ou Python ?

Les deux sont excellents. R brille particulièrement pour la statistique, les rapports et la visualisation exploratoire. Ce livre se concentre sur R ; les compétences (logique, données, visualisation) se transfèrent ensuite.

2.6 Présentation de R, RStudio et Quarto

  • R : le moteur (langage + environnement statistique).
  • RStudio Desktop (Posit) : l’interface recommandée (éditeur, console, graphiques, fichiers).
  • Quarto : système de publication pour écrire ce livre et vos rapports (HTML, PDF, Word).

RStudio n’est pas obligatoire : vous pouvez utiliser VS Code, Positron ou la console R. Pour débuter, RStudio reste le choix le plus confortable.

2.7 Installation et configuration

2.7.1 1. Installer R

  1. Téléchargez R depuis https://cran.r-project.org/
  2. Choisissez votre système (Windows, macOS, Linux)
  3. Installez en suivant l’assistant (options par défaut acceptables)

Vérification dans un terminal :

R --version
# ou
Rscript --version

2.7.2 2. Installer Quarto

Téléchargez Quarto depuis https://quarto.org/docs/get-started/ puis vérifiez :

quarto --version

Sous Windows, Quarto peut aussi être fourni avec RStudio (dossier resources/app/bin/quarto).

2.7.3 3. Installer RStudio Desktop (recommandé)

Téléchargez depuis https://posit.co/download/rstudio-desktop/.

2.7.4 4. Installer les packages du livre

Dans la console R :

source("R/packages_requis.R")

Ou manuellement :

install.packages(c(
  "tidyverse", "readxl", "broom", "shiny",
  "janitor", "gt", "scales", "writexl"
))

2.7.5 5. PDF : distribution LaTeX

Pour générer le PDF du livre :

install.packages("tinytex")
tinytex::install_tinytex()
Attention

L’installation de TinyTeX peut prendre plusieurs minutes et nécessite une connexion Internet. Le rendu HTML et DOCX ne l’exigent pas.

2.8 Premier programme en R

Ouvrez RStudio (ou une session R) et saisissez :

# Calcul simple
2 + 2
#> [1] 4
# Affectation : on stocke un résultat dans un objet
montant <- 19.90
quantite <- 3
total <- montant * quantite
total
#> [1] 59.7
# Afficher un message
message("Bienvenue dans l'analyse de données avec R !")

2.8.1 Anatomy d’une session

  • <- : opérateur d’affectation (lire « reçoit »)
  • # : commentaire (ignoré par R)
  • La console exécute ligne par ligne ; un script .R enregistre le code
# Un vecteur de notes
notes <- c(12, 15, 9, 18, 14)
mean(notes)   # moyenne
#> [1] 13.6
sd(notes)     # écart-type
#> [1] 3.361547
summary(notes)
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max.
#>     9.0    12.0    14.0    13.6    15.0    18.0
Erreur fréquente

= fonctionne souvent comme <-, mais la convention pédagogique en R est <-. Évitez de confondre == (comparaison) et <- (affectation).

2.9 Organisation d’un projet d’analyse

2.9.1 Structure recommandée

mon-projet/
├── data/           # données brutes et nettoyées
├── R/              # scripts réutilisables
├── reports/        # fichiers .qmd
├── outputs/        # figures et tableaux exportés
└── README.md

2.9.2 Bonnes pratiques dès le premier jour

  1. Un projet RStudio (fichier .Rproj) ancre le répertoire de travail.
  2. Ne modifiez pas les données brutes : gardez une copie intacte dans data/brut/.
  3. Tout le traitement dans des scripts : pas de clics non documentés.
  4. Noms de fichiers explicites : nettoyer_ventes.R, pas script2.R.
# Connaître le dossier de travail
getwd()

# Lister les fichiers de données
list.files("data")

Dans ce livre, les chemins sont relatifs au dossier formation-r/.
