could not find function Package non chargé library(...)

PDF Quarto échoue Pas de LaTeX tinytex::install_tinytex()

# Références, annexes et navigation {#sec-annexes}

## Introduction

Cette partie regroupe les ressources de révision : glossaire détaillé (@sec-glossaire), aide-mémoires (@sec-aide-memoire), guide d'erreurs, références officielles et pistes de publication.

## Guide des erreurs fréquentes

| Message / symptôme | Cause fréquente | Solution |
|--------------------|-----------------|----------|
| `object 'x' not found` | Objet non créé / typo | `ls()`, revérifier le chunk |
| `could not find function` | Package non chargé | `library(...)` |
| `Cannot open file` | Mauvais chemin | `getwd()`, projet RStudio |
| `unexpected ')'` | Parenthese en trop/manquant | Repérer la ligne du `+` console |
| PDF Quarto échoue | Pas de LaTeX | `tinytex::install_tinytex()` |
| Jointure explosée | Clés dupliquées | `count(id)` avant join |
| Graphique vide | Données filtrées à 0 lignes | `nrow()` avant ggplot |
| Facteur → nombres bizarres | Conversion directe | `as.numeric(as.character(f))` |

## Tableau des fonctions R essentielles

| Fonction | Rôle |
|----------|------|
| `c()` | Créer un vecteur |
| `data.frame()` / `tibble()` | Tableau |
| `mean`, `median`, `sd`, `summary` | Descriptifs |
| `read_csv` / `write_csv` | Import / export CSV |
| `filter`, `select`, `mutate` | Transformation |
| `group_by`, `summarise` | Agrégation |
| `left_join` | Jointure |
| `ggplot` + `geom_*` | Visualisation |
| `lm`, `t.test`, `cor.test` | Modèles / tests |
| `set.seed` | Reproductibilité |

## Publication GitHub Pages (facultatif)

1. Créer un dépôt Git et pousser les **sources**
2. Rendre le livre : `quarto render --to html`
3. Publier le contenu de `outputs/book/` (Actions ou branche `gh-pages`)
4. Documenter l'URL dans le README

Le livre reste consultable **localement** sans compte externe : ouvrez `outputs/book/index.html`.

```bash
# Régénérer les données synthétiques

# Vérifier / installer les packages
Rscript R/packages_requis.R

# Rebuild
quarto render --to html
```
